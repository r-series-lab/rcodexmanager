# Support / 获取帮助

- 使用说明：[rcm.rurie.top](https://rcm.rurie.top)
- Bug 与功能建议：[GitHub Issues](https://github.com/r-series-lab/rcodexmanager/issues)
- 安全问题：按 [SECURITY.md](SECURITY.md) 私下报告

提交问题时请提供 rCodexManager 版本、控制端和执行端系统、架构、复现步骤、预期结果和已脱敏的 Doctor 输出。不要上传 Token、OAuth URL、设备码、Cookie、API Key、认证备份、SSH 配置正文或完整私人路径。

For help, start with the [official documentation](https://rcm.rurie.top/en/docs), then use GitHub Issues for reproducible bugs and feature requests. Include the app version, control and execution OS, architecture, reproduction steps, expected behavior, and redacted Doctor output. Report vulnerabilities privately through [SECURITY.md](SECURITY.md).
